### 本机命令注意（重要）

`flutter` **不在 PATH**，统一用 dart snapshot：

```powershell
$dart = "D:\apps\flutter\bin\cache\dart-sdk\bin\dart.exe"
$snap = "D:\apps\flutter\bin\cache\flutter_tools.snapshot"

cd d:\Jules\Projects\Agent\LifeLog\app

# 静态检查
& $dart $snap analyze

# 全量自动化
& $dart $snap test ..\testcases\automation --reporter compact

# 构建模拟器用 release APK（必须 cwd=app）
& $dart $snap build apk --release --target-platform android-x64
```

- 跑测试前若报 `Failed to delete sqlite3.dll`：
  `Get-Process dart, flutter_tester -ErrorAction SilentlyContinue | Stop-Process -Force`
- 改数据表后重新生成 Drift 代码：
  `& $dart run build_runner build --delete-conflicting-outputs`
- 真机（ARM）打包去掉 `--target-platform android-x64`，或显式 `android-arm64`。

## 5. 已完成功能明细

### 5.1 财务

- 记账：支出 / 收入 / 转账；金额以「分」存整数；分类按方向过滤；可选账户、时间、商户、备注。
- 账户：现金、储蓄卡、信用卡、微信、支付宝、投资账户；银行卡只存前四位（选填）与后四位（必填），列表显示「招商银行(0137)」。
- 分类：支出 / 收入分类独立管理。
- 总览（本轮改版）：
  - 周期：**周 / 月 / 年**（原「日」已移除）。
  - 周期条：最近 26 周 / 24 个月 / 10 年，可左右滑动，点击选择；「本周 / 上周 / 本月 / 上月 / 今年 / 去年」特殊标注；跨年月份显示「25年12月」。
  - 汇总：收入 / 支出 / 结余三卡 + 笔数 + 日期范围 + 平均值（所选方向的总额 ÷ 笔数）。
  - 趋势：收入绿、支出蓝双折线；周视图 7 个日号，月/年视图最多 6 个日期标签。
  - 分类占比：饼图保留，支持支出/收入切换；单分类圆心显示名称与 100%。
  - 收支排行：按金额降序，含分类图标、占比、进度条、金额。
- 流水明细：关键词搜索、类型筛选、日期区间、编辑 / 删除。
- 预算：按月份、总预算 / 分类预算、进度与超支提示。
- 资产管家：净资产渐变卡、资产/负债、按账户类型分组、实时余额（初始 + 收入 − 支出）。
- AI 识图记账 + 支付截图草稿确认（需人工确认后才入库）。

### 5.2 健康

- **周 / 月 / 年周期，交互与财务一致**：分段切换 + 横滑周期条（本周/上周、本月/上月、今年/去年特殊标注，最近 26 周 / 24 个月 / 10 年），周期条下方显示区间提示；体重/围度趋势周、月按天、年按月。学习模块仍保留日/月/年。
- 体重：记录、体脂率、备注、趋势、区间变化/最低/最高、BMI（需设置身高）。
- 趋势图 X 轴只在有数据的点上均匀取最多 6 个标签（周按天、月按天、年按月），不重叠、不留空白日期。
- 围度：长表结构，多部位（腰围/胸围/臀围等可扩展），每部位趋势。
- 运动：类型、时长、距离、消耗、平均心率、备注；按类型时长条形统计。
- 三个记录弹层均有「取消」按钮；编辑态含「删除」。
- 本轮在模拟器造了 2026-06-24~10-22 共 120 天的体重 112 条、围度 72 条、运动 53 条，用于验证周/月/年趋势效果（截图 hs01~hs09）。

### 5.4 AI 助手

- 助手默认名「**小朝**」，用户可在 AI 页顶栏或「我的 → AI 助手 → 助手名称」随时改名（最长 12 字，存 `AppSettings.assistant_name`）；标题与欢迎语联动。
- 多轮对话、会话列表、新会话、抽屉。
- **流式输出**：SSE 逐段追加，正文到达前显示「正在思考…」；工具调用分片按 index 拼接，最多 3 轮工具调用。
- 回复以 **Markdown** 渲染（标题/粗体/列表/表格/代码块），不再直接显示 `**` `-` `#` 等原始符号；长按任意消息可「复制这条 / 复制整段对话」。
- **语音输入**：输入框右侧麦克风，识别中间结果实时填入输入框；设备无语音服务或拒绝权限时提示改用键盘，不崩溃。
- DeepSeek Function Calling 读写本地财务/健康/学习数据，支持**最多 3 轮工具调用串联**；系统提示词携带助手名。共 **16 个工具**（`data/ai/toolset.dart`）：
  - 财务 8 个：`create_transaction`（可指定账户/备注）、`create_transfer`（按账户名/卡号尾号匹配转账）、`query_expense`（日/周/月/年）、`list_accounts`（实时余额+总资产）、`create_account`、`list_categories`、`set_budget`（同月覆盖）、`query_budget`（已花/剩余）。
  - 健康 5 个：`create_weight_record`、`create_measure_record`、`create_workout_record`、`query_health`（体重/体脂/BMI/围度/运动汇总）、`set_height`。
  - 学习 2 个：`query_study`（今日/30 天待复习队列、词库）、`add_study_word`（词库不存在自动建）。
  - 综合 1 个：`get_overview`（财务/资产/预算/健康/学习一次汇总）。
- 账户/分类等匹配不到时返回结构化失败（ok=false），助手据错误用人话追问，不臆测。
- 上传图片识别：支付截图 → 记账草稿；体重截图；围度截图（多部位）。
- 未配置 Key 时本地规则记账；断网入队，联网后自动重放。
- API Key 存 Android Keystore，界面掩码显示，可修改/清除。

### 5.5 安全与备份

- PIN：首次设置 + 二次确认，PBKDF2 哈希存储，错误提示与连续错误次数。
- 「启动免 PIN」开关：开启后冷启动直接进主界面；「立即锁定」仍要求 PIN。
- 指纹解锁：已设 PIN 且设备已录入指纹时，锁屏自动拉起验证；失败/取消可点「指纹解锁」重试，PIN 始终可用；无指纹设备不显示按钮。
- 后台超过 5 分钟回前台需重新解锁（免 PIN 开启时不回锁）。
- 加密备份：AES-256-GCM + PBKDF2；导出 / 导入、覆盖恢复 / 合并导入、错误密码与篡改检测、事务回滚。
- 应用图标与名称「朝夕册」已全量替换。

### 5.6 外观与主题色

- 「我的 → 外观 → 主题颜色」提供 6 种主题色（晨绿默认 / 海蓝 / 靛紫 / 暖橙 / 玫红 / 青碧），选择后即时生效并持久化（`AppSettings.theme_accent`）。
- 主题色通过 `ColorScheme.fromSeed` 驱动全局：导航栏、按钮、周期条、图表主色同步切换；收入绿/支出红等语义色保持不变。

### 5.7 回收站与 CSV 导出

- 「我的 → 回收站」：聚合流水、账户、分类、预算、体重、围度、运动、单词、词库 9 类软删除记录。
- 恢复：清除 `deletedAt`；恢复词库时按相同删除时间级联恢复其单词。
- 彻底删除：物理删除，并清理关联的复习记录与测验作答；清空回收站在事务内逐条执行。
- 「我的 → 导出 CSV」：流水、体重、围度、运动、学习统计、测验记录六类。
- CSV 格式：UTF-8 BOM + CRLF，字段含逗号/引号/换行时双引号包裹并转义；金额元、体重 kg、围度 cm、距离 km。
- 只导出未删除数据；生成后写入应用文档目录并通过系统分享保存。
